# Matthew Reath

Personal site.

## Run

```bash
npm install
npm run dev
```

http://127.0.0.1:43217

## Deploy

```bash
set GITHUB_PAGES=true
set NEXT_PUBLIC_SITE_URL=https://compl3xlife.github.io/matthew-reath
npm run build
npx gh-pages -d out -b gh-pages --dotfiles -m "deploy"
```
